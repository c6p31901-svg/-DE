海岸美化財団 管理者画面（投稿マップ組み込み版）

【起動方法】
1. ZIPをすべて同じフォルダに解凍します。
2. VS Codeでこのフォルダを開き、Live Server拡張機能などのローカルサーバーで index.html を開いてください。
3. ダッシュボードの「投稿マップ」に、アップロードされたHTMLのLeaflet地図レイヤーを表示します。

【組み込んだ内容】
・地理院タイル（航空写真）
・ごみ量「中」の黄色円、ごみ量「多」の赤色円
・注射器発見要注意区域の紫色円
・危険物の警告マーカー
・提供されたGeoJSONを「trash_places.geojson」という名前で読み込む処理

【現在のGeoJSONについて】
提供されたGeoJSON（trash_places.geojson）は FeatureCollection の features が空（地点0件）です。そのため、GeoJSON由来のごみ置き場ピンは現時点では表示されません。地点データをGeoJSONに追加すると、緑色で地図に表示されます。

【補足】
・以前の投稿マップのSVG模式図は、実際の地図に置き換えています。
・現在の投稿情報（6件）は場所名のデモデータで緯度・経度を持っていないため、それぞれの投稿ピンとはまだ連動していません。
・地図タイルとLeafletはインターネット接続が必要です。
・管理者ページでは閲覧者の現在地を追跡しない設定です。
